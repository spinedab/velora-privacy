Privacy Policy - Velora Expenses

Last updated: September 2026

Overview

Velora Expenses is a local-only Chrome extension that helps you keep a personal expense ledger in the side panel: it can read tables from the page you are viewing when you click "Scan tables", lets you map their columns, and stores the resulting entries on your device. It is a bookkeeping aid and does not provide financial, tax or investment advice. It makes no network requests of any kind.

Data Collection

Velora Expenses does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All entries, category rules and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Page reads on demand. The extension reads the tables of the active tab only when the user clicks "Scan tables on this page". The read is read-only: the extension never modifies, clicks, submits or types into any page.
  • User-controlled export/import. Entries can be exported to CSV or JSON, or imported from a JSON backup, only through an explicit user action and Chrome's download dialog. Nothing is uploaded anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

Velora Expenses makes no network requests of any kind. It does not call any AI provider or any other service.

Page Access

Velora Expenses does not declare content scripts and has no host permissions. Access to a page is granted per click through activeTab, and the only code executed on the page is a self-contained read-only function that lists the tables it contains.

Permissions Explained

  • sidePanel - renders the ledger in Chrome's side panel.
  • storage - saves entries and category rules locally.
  • activeTab - grants temporary access to the current tab only after you click, so tables can be read on demand.
  • scripting - runs the read-only table reader in the active tab when you click "Scan tables".
  • downloads - saves the CSV or JSON files you export through Chrome's download dialog.

Data Deletion

All data can be removed at any time with "Delete all entries and rules" inside the panel or by uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.
