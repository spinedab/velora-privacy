Privacy Policy - Velora Write

Last updated: September 2026

Overview

Velora Write is a local-only Chrome extension that provides a long-form writing workspace in the side panel, with optional AI suggestions applied per paragraph. It is designed with a privacy-first architecture.

Data Collection

Velora Write does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All documents, outlines, revision history, snapshots, API keys, and preferences are stored exclusively in chrome.storage.local on the user's device. Snapshots (manual, or automatic every 5 minutes while editing, last 10 per document) are copies of your own document kept locally so you can restore them.
  • Paragraph-level AI for editing helpers. "Improve paragraph", "Tighten prose" and the BYOK fallback of "Rewrite locally" send only the specific paragraph you selected.
  • Whole-document AI only for two explicit features. "Document chat" and "Tone analyzer" send the full current document (plus your question, for chat) to the AI provider when you click Ask / Analyze tone. The panel states this next to each button. Nothing is sent automatically.
  • On-device AI (optional). "Rewrite locally" tries Chrome's built-in on-device model first. When Chrome reports it as available, the paragraph is processed on your device and does not leave the browser. When it is not available, the panel says so and uses your API key instead. Availability depends on your Chrome version and hardware.
  • User-controlled exports. The user may explicitly export a document to Markdown, JSON or HTML using the downloads permission. HTML is rendered locally by the extension. Nothing is downloaded without a user action.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks an AI action. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the paragraph the user selected for paragraph helpers, or the whole current document for "Document chat" and "Tone analyzer".
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls. The automatic 5-minute snapshot is a local copy in chrome.storage.local and involves no network request.

The extension developer has no access to the user's API key or documents. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Write does not request activeTab, scripting, or any host permission other than api.groq.com. It does not read or modify any web page. All writing happens inside the side panel's own editor.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
