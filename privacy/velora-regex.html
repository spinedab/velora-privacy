Privacy Policy - Velora Regex

Last updated: September 2026

Overview

Velora Regex is a local-only Chrome extension that provides a regular-expression workbench in the side panel: test a pattern against your own sample text, inspect matches and capture groups, preview substitutions, read a plain-language explanation of the pattern, and keep a library of saved patterns. It is designed with a privacy-first architecture.

Data Collection

Velora Regex does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Your pattern, flags, test text, replacement string, saved pattern library and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • No page access. The extension does not read, modify, or interact with any web page. It has no content scripts and no activeTab, scripting or tabs permission. All text is typed or pasted into the panel. This is deliberate: testing patterns against real data (emails, phone numbers, IDs) should never involve a third-party website.
  • Pattern execution stays local. Matching runs inside a dedicated Web Worker (regex-worker.js) on your device, never with eval and never on a server. The worker is given a time budget and is terminated if a pattern backtracks catastrophically, so a runaway expression cannot freeze the panel.
  • The explainer is local. The plain-language breakdown of a pattern is produced by a tokenizer written in JavaScript that runs on your device with no network request and no API key.
  • Clipboard on demand. The clipboard is written only when you click a Copy button. The clipboard is never read.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when you explicitly click "Explain in plain words" or "Generate from description". This request:

  • Uses your own Groq API key, which you provide and store locally.
  • Sends only the pattern you are inspecting or the description you typed. Your test text is never sent.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to your API key, patterns, or test data. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Permissions Explained

  • sidePanel - renders the regex workbench in Chrome's side panel.
  • storage - saves your pattern, test text, saved library and the optional API key locally.
  • clipboardWrite - copies a pattern, a match or a substitution result when you click Copy.
  • host permission for api.groq.com - allows the optional, user-initiated explain and generate requests.

Data Deletion

All data can be removed at any time by deleting saved patterns inside the panel, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
