Privacy Policy - Velora CSS

Last updated: September 2026

Overview

Velora CSS is a local-only Chrome extension that lets you inspect the computed styles of elements on the page you are viewing, from the side panel: box model, typography, colors, layout, a copyable CSS snippet and Tailwind hints. It is designed with a privacy-first architecture.

Data Collection

Velora CSS does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • No network requests of any kind. This extension has no host permissions and makes no fetch, XHR, WebSocket or beacon calls. There is no AI, no API key and no server component.
  • Local storage only. Your inspection history (the selector, the size and the generated CSS snippet) and your pinned items are stored exclusively in chrome.storage.local on the user's device. Page content is not stored — only the style summary of elements you clicked.
  • Inspecting is explicit and temporary. Nothing is injected until you click "Start inspecting". While inspecting, the extension adds one element to the page: an overlay host called <velora-css-inspector> with a Shadow DOM, used to draw the highlight box and its label. "Stop" removes that element and both event listeners; reloading the page also removes it.
  • What it reads. While inspecting, it reads the geometry (getBoundingClientRect) and the computed styles (getComputedStyle) of the element under your cursor, plus its tag, id and class names. It does not read page text, form values, cookies, storage, or anything you type.
  • The first click is intercepted. So that clicking an element captures it instead of navigating, the inspector prevents the default action of that one click. Every interaction after Stop behaves normally.
  • Nothing else is modified. The extension never clicks, submits, fills forms, navigates, or changes the page's own content or styles.
  • Reads are always manual. Nothing is inspected in the background and no other tab is accessed.
  • Clipboard on demand. The clipboard is written only when you click Copy. The clipboard is never read.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

Page Access

Velora CSS declares no persistent content scripts and no host permissions. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to inject the inspector when you press Start and to remove it when you press Stop.

Chrome forbids injection on some pages (chrome:// URLs, the Chrome Web Store, the built-in PDF viewer). On those the panel reports that instead of failing silently.

Permissions Explained

  • sidePanel - renders the inspector in Chrome's side panel.
  • storage - saves your inspection history and pinned items locally.
  • activeTab - temporary access to the current page, only after you click Start inspecting.
  • scripting - injects the overlay when you start and removes it when you stop.
  • clipboardWrite - copies a CSS snippet or a color when you click Copy.

Data Deletion

History and pinned items can be deleted individually or cleared from the panel. Uninstalling the extension removes all locally stored data.
