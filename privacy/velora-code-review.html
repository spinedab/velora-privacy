Privacy Policy - Velora Code Review

Last updated: April 2026

Overview

Velora Code Review is a local-only Chrome extension that assists developers in reviewing GitHub pull requests. It surfaces the diff of the current PR in a side panel and, on explicit user action, sends it to an AI model for a review checklist and suggestions. It is designed with a privacy-first architecture.

Data Collection

Velora Code Review does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All user preferences, API keys, custom review checklists, and saved review notes are stored exclusively in chrome.storage.local on the user's device. Nothing is sent to any server operated by the extension developer.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind. It does not authenticate to GitHub.
  • Read-only on GitHub. The extension reads the diff of the pull request the user is viewing only when the user clicks a review action. It never writes, comments, approves, or merges.

External API Usage

The only AI-related external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Review" or another analysis action. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends the selected portions of the current PR diff and the user's chosen checklist settings to the Groq API to produce review suggestions.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension also reads from github.com tabs (only the active tab, only on user action) to extract the PR diff. It does not make any authenticated API requests to github.com; it relies on what is already visible in the user's logged-in browser session.

The extension developer has no access to the user's API key, diff content, or review output. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

GitHub Page Access

When the user clicks a review action on a GitHub PR page, the extension reads the diff content visible in that tab to build the AI prompt. It does not:

  • Post comments, reviews, approvals, or merges.
  • Modify the PR page in any way.
  • Access repositories, issues, or pages the user is not currently viewing.
  • Make any authenticated API calls on the user's behalf.

Permissions Justification

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
