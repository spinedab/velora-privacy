Privacy Policy - Velora Tok

Last updated: August 2026

Overview

Velora Tok is a local-only Chrome extension that gives TikTok creators a side panel command center: a content planner with reminders, AI-assisted captions, hooks and scripts, hashtag sets, a local metrics tracker for videos, and a comment reply assistant. It is designed with a privacy-first, human-in-the-loop architecture: it never posts, likes, follows, comments, or sends anything on the user's behalf. The user always performs the final action on TikTok.

Data Collection

Velora Tok does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Plans, captions, notes, hashtag sets, captured video metrics, captured comments, the creator profile, and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • Capture on demand. Video metrics, profile grid data, and comments are read from the TikTok page the user is currently viewing, only when the user clicks a capture button. Nothing is read in the background and no other tab is accessed.
  • Reminders are local. Scheduled reminders use Chrome's alarms and notifications. A reminder only shows a notification; clicking it opens the TikTok upload page in a new tab. The extension does not upload files, fill forms, or press Post.
  • Clipboard on demand. The clipboard is written only when the user clicks a Copy button. The clipboard is never read.
  • User-controlled exports. CSV metrics and JSON backups are downloaded only when the user requests them. Backups never include the API key.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind, and it never accesses the user's TikTok credentials or session.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks an AI button (captions, hooks, script, ideas, optimize, translate, hashtag suggestions, comment triage). This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the text needed for that action: the topic or caption the user typed, the optional creator profile fields, and, for comment triage, the captured comment texts.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key, content, or metrics. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Tok declares no persistent content scripts. It has host access to www.tiktok.com so that, when the user clicks Capture, it can run a one-time read-only script on the active TikTok tab to read publicly visible information: the open video's caption, hashtags, and public counters (views, likes, comments, shares, saves), the open profile's public grid and counters, or the comments currently rendered on screen. It does not modify pages, does not interact with TikTok's interface, and does not read private messages, drafts, or account settings.

Permissions Explained

  • sidePanel - renders the command center in Chrome's side panel.
  • storage - saves plans, sets, metrics, comments, profile, and the optional API key locally.
  • scripting - runs the one-time read-only capture on the active TikTok tab when you click Capture.
  • alarms - fires your posting reminders at the time you chose.
  • notifications - shows the reminder notification.
  • clipboardWrite - copies captions, hashtags, and reply drafts when you click Copy.
  • downloads - saves CSV metrics and JSON backups when you request them.
  • host permission for www.tiktok.com - allows the capture script to read the TikTok page you are viewing.
  • host permission for api.groq.com - allows the optional, user-initiated AI requests.

Data Deletion

All data can be removed at any time from Settings ("Delete all local data"), by deleting individual items, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
