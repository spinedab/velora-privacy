Privacy Policy - Velora Tabs

Last updated: September 2026

Overview

Velora Tabs is a local-only Chrome extension that organizes the tabs of the current window from the side panel: grouping by domain, finding duplicates, collapsing groups and saving sessions. It makes no network requests of any kind.

Data Collection

Velora Tabs does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Saved sessions (tab URLs, titles, group names and colors) are stored exclusively in chrome.storage.local on the user's device, and only when the user clicks "Save session".
  • Tab metadata in memory. While the panel is open, the extension reads the titles, URLs and group information of the tabs in the current window to display them. This information is not persisted unless you save a session, and it is never sent anywhere.
  • Actions only on click. Grouping, ungrouping, collapsing, switching and closing tabs happen only in response to an explicit click in the panel. Closing duplicate tabs additionally requires a confirmation step.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

Velora Tabs makes no network requests of any kind. It does not call any AI provider or any other service.

Page Access

Velora Tabs does not declare content scripts, has no host permissions and does not request the scripting permission. It cannot read or modify the content of any web page; it only works with tab metadata (title, URL, group) provided by Chrome's tabs API.

Permissions Explained

  • sidePanel - renders the tab organizer in Chrome's side panel.
  • storage - saves your sessions locally.
  • tabs - lists the tabs of the current window (title, URL, favicon) and lets you switch, group or, after confirmation, close them.
  • tabGroups - creates, names, colors, collapses and expands tab groups.

Data Deletion

Saved sessions can be deleted one by one inside the panel. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.
