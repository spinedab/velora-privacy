Privacy Policy - Velora Research

Last updated: September 2026

Overview

Velora Research is a local-only Chrome extension that acts as a reading and research assistant. The user highlights text on any web page and can request an AI-powered summary, explanation, or translation. It is designed with a privacy-first architecture.

Data Collection

Velora Research does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All user preferences, API keys, saved highlights, tags, and research notes are stored exclusively in chrome.storage.local on the user's device. Nothing is sent to any server operated by the extension developer.
  • No external analytics or telemetry. The extension maintains a local library of saved highlights with user-assigned tags for the user's own reference. This data never leaves the browser.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com when the user explicitly triggers an AI action (Summarize, Explain, Translate, "Define in context", or "Fill missing fields with AI") through the context menu or side panel. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends the currently selected text (plus its surrounding paragraph for "Define in context"), or the page metadata and the first part of the article text for "Fill missing fields with AI", to the Groq API to produce the requested output.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or to any data sent to or received from api.groq.com. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Content Access

The extension reads from the active page only when the user clicks a button, using read-only scripts:

  • Selection and its surrounding paragraph (Read selection, Define in context).
  • Page metadata such as title, author, date, publisher, DOI (Cite this page).
  • HTML tables (Table to CSV). The CSV is generated locally and downloaded by the user.
  • Main article text, only for "Fill missing fields with AI", and only the first part of it.

It never clicks, submits forms, posts, or modifies any page. It does not monitor browsing activity. Highlights are only saved locally when the user chooses to save them.

Tab Titles and URLs (Session index)

When the user clicks "Build index", the extension reads the title and URL of the tabs in the current window to produce a Markdown list of sources. It does not read the content of those tabs, does not store the list, and does not transmit it anywhere. The list only appears in the side panel for the user to copy.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
