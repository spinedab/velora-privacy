Privacy Policy - Velora Translate

Last updated: April 2026

Overview

Velora Translate is a local-only Chrome extension that provides context-aware AI translation for text the user selects on any web page. It maintains a personal glossary and translation memory entirely on the user's device. It is designed with a privacy-first architecture.

Data Collection

Velora Translate does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All user preferences, API keys, personal glossary entries, and translation memory are stored exclusively in chrome.storage.local on the user's device. Nothing is sent to any server operated by the extension developer.
  • Personal glossary. Term-to-translation pairs the user defines are stored locally and used to influence future translations for consistency. These never leave the browser.
  • Translation memory. Previously translated segments are cached locally so repeated phrases are not re-sent to the API. This cache lives only on the user's device.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com when the user explicitly triggers a translation. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends the selected text, target language, and optionally a small set of relevant glossary terms to the Groq API.
  • Is initiated exclusively by manual user action (context menu click or side panel button); there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or to any data sent to or received from api.groq.com. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Content Access

The extension only reads text that the user has explicitly highlighted on the active page. It does not read the rest of the page, track browsing behavior, or run continuously.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
