Privacy Policy - Velora Translate JSON

Last updated: September 2026

Overview

Velora Translate JSON is a local-first Chrome extension that translates the values of an i18n JSON file while keeping its keys, key order and placeholders intact. Parsing, flattening, placeholder verification and export all happen on your device; the translation itself is an explicit, batched request using your own API key. It is designed with a privacy-first architecture.

Data Collection

Velora Translate JSON does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • No page access whatsoever. The extension has no activeTab, no scripting, no tabs permission and no content scripts. It cannot read any web page. Files come from your disk (drag and drop or the file picker) or from the paste box.
  • Local storage only. Your options (languages, glossary, skip patterns, batch size), the translation memory and the optional API key are stored exclusively in chrome.storage.local on the user's device. The loaded file itself is not persisted — it lives in the panel for the session and is gone when you close it.
  • The translation memory. Strings you have already translated are remembered, keyed by target language, so re-running a file costs almost nothing. It holds the source string and its translation, nothing else, capped at 4,000 entries, and you can clear it with one click.
  • Everything except the translation is local. JSON parsing and validation, flattening to dotted paths, placeholder extraction and verification, ICU plural grouping, batch planning, key-order-preserving reassembly, and the JSON and CSV exports all run in JavaScript on your device with no network request and no API key.
  • User-controlled downloads. The translated .json and the review .csv are saved only when you click Download.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when you click "Translate values". This request:

  • Uses your own Groq API key, which you provide and store locally.
  • Sends, in batches, the paths and the string values that need translating — plus your glossary and the target language. Values already covered by the local memory are never sent. Keys you excluded with a skip pattern are never sent. Non-string values and empty strings are never sent.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls. You can cancel between batches, and whatever was already translated is kept.

Be deliberate about what you upload. An i18n bundle is usually product copy, but if yours contains anything confidential, that content will be sent to Groq when you press Translate. The extension will not do it without that click, and the review table shows exactly what it holds before you do.

The extension developer has no access to your API key or your files. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Permissions Explained

  • sidePanel - renders the workspace in Chrome's side panel.
  • storage - saves your options, the translation memory and the optional API key locally.
  • downloads - saves the translated .json or the review .csv when you click Download.
  • host permission for api.groq.com - allows the user-initiated translation requests.

Data Deletion

The translation memory can be cleared from the panel; "Forget key" removes the API key; the loaded file is discarded when you close the panel. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
