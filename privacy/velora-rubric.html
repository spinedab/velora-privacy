Privacy Policy - Velora Rubric

Last updated: September 2026

Overview

Velora Rubric is a local-first Chrome extension that lets teachers grade student text against their own rubrics in the side panel, with an optional AI-suggested evaluation. It is designed with a privacy-first architecture.

Data Collection

Velora Rubric does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Rubrics, grade history, the optional API key and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Student text stays on the device by default. Pasted or selected text is only kept in the panel while you work with it. Grade history stores a short non-reversible hash of the text, the rubric name, the scores and the date, not the text itself.
  • Page reading on demand. The active page is read only when the user clicks "Read selection", and only the currently highlighted text is returned. The extension never modifies pages, never clicks or submits anything on them, and never reads pages in the background.
  • User-controlled export. Grade history can be exported as a CSV file only through an explicit user action. Nothing is uploaded anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Evaluate with AI". This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the rubric (criteria names, descriptions, points) and the student text the user chose to evaluate.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.
  • Returns a suggestion that is always labeled "Suggestion — review before grading". The teacher decides the final grade.

The extension developer has no access to the user's API key, rubrics or student text. Usage of the Groq API is governed by Groq's own terms of service and privacy policy. All non-AI features work without a key and without any network access.

Page Access

Velora Rubric does not inject content scripts. When the user clicks "Read selection", a small read-only function runs once in the active tab and returns the selected text and the page title. It does not change the page.

Permissions Explained

  • sidePanel - renders the rubric editor and grading sheet in Chrome's side panel.
  • storage - saves rubrics, grade history and the optional API key locally.
  • activeTab - grants temporary access to the current tab only after the user clicks "Read selection".
  • scripting - runs the one-off, read-only selection reader in the active tab on click.
  • host permission for api.groq.com - allows the optional, user-initiated AI evaluation request.

Data Deletion

All data can be removed at any time by deleting rubrics or history entries inside the panel, clicking "Clear history", clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
