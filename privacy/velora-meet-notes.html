Privacy Policy - Velora Meet Notes

Last updated: September 2026

Overview

Velora Meet Notes is a local-only Chrome extension that provides a side-panel notepad for users taking manual, typed notes during Google Meet calls. It is designed with a privacy-first architecture and strict compliance with Google Meet's terms of service.

Critical Privacy Statement

This extension does NOT record audio. It does NOT record video. It does NOT perform or request transcription of any kind. It does NOT capture participant names, participant lists, chat contents, or any meeting media.

The only content stored or processed is text that the user personally types into the extension's notepad. Nothing else from the meeting is accessed, read, intercepted, or captured.

Data Collection

Velora Meet Notes does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. User-typed notes, meeting labels, API keys, and preferences are stored exclusively in chrome.storage.local on the user's device.
  • No media capture. The extension has no access to microphone, camera, tab audio, or tab video. The Chrome manifest does not request any such permissions.
  • No automatic content reading. The extension does not read participant names, the attendee list, chat messages, shared presentations, or any other Meet UI element.
  • User exports. The user may explicitly export their own typed notes or extracted minutes as a Markdown or JSON file using the downloads permission. Nothing is downloaded without an explicit user action.
  • Clipboard. "Copy Notion Markdown" and "Copy email" write text to the clipboard only when the user clicks them (clipboardWrite). The extension never reads the clipboard.
  • Session buffer. While you type, the notes textarea is mirrored into chrome.storage.session so an accidentally closed panel can restore them. This buffer lives only in browser memory and is discarded when the browser closes.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Structure notes with AI", "Extract minutes" or "Draft email" on their own typed notes. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the text the user typed into the notepad and explicitly chose to process.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or note content. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Google Meet Page Access

Host permission on meet.google.com is used only so the side panel can be attached to Meet tabs and so the extension can tell the user which meeting URL the current notes are associated with. The extension does not read, extract, or transmit any content from the Meet page itself.

Permissions Justification

PermissionPurpose
sidePanelOpens the note-taking UI as a Chrome side panel beside the Meet window
activeTabDetects that the current tab is a Google Meet URL so notes can be labeled with that meeting
storageSaves typed notes, meeting labels, API key, and preferences in chrome.storage.local
downloadsLets the user explicitly export their own typed notes or extracted minutes as a .md or .json file. Used only on user click.
clipboardWriteCopies the Notion-flavored Markdown minutes or the follow-up email draft to the clipboard when the user clicks Copy. Write-only; the clipboard is never read.
host_permissions: api.groq.comSends note cleanup/summary requests (on user-typed text only) using the user's own API key
host_permissions: meet.google.comAllows the side panel to associate notes with a Meet tab URL. No Meet page content is read or transmitted.

Compliance With Google Meet Terms

This extension is designed to respect Google Meet's terms of service. Because it performs no recording and no transcription, it cannot be used to capture a meeting without participants' consent. Users remain responsible for informing meeting participants that they are taking written notes, as they would with pen and paper.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
