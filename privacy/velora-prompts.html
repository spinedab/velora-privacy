Privacy Policy - Velora Prompts

Last updated: September 2026

Overview

Velora Prompts is a local-only Chrome extension that provides a personal library of AI prompts with {variable} substitution, tags, search and version history in the side panel. It is designed with a privacy-first architecture and makes no network requests at all.

Data Collection

Velora Prompts does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All prompts, tags, model hints, version history and remembered variable values are stored exclusively in chrome.storage.local on the user's device.
  • Clipboard on demand. The clipboard is only written when the user clicks Copy on a specific prompt. The extension never reads the clipboard.
  • User-controlled import/export. Prompts can be exported to or imported from a JSON file only through an explicit user action. Nothing is uploaded anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

Velora Prompts makes no external network requests. It does not call any AI provider; it only stores prompts so the user can paste them into the tool of their choice.

Page Access

Velora Prompts does not inject content scripts and does not read the content of any web page. It runs entirely inside its own side panel.

Permissions Explained

  • sidePanel - renders the prompt library in Chrome's side panel.
  • storage - saves prompts, tags, history and remembered values locally.
  • clipboardWrite - copies a prompt to the clipboard when the user clicks Copy.

Data Deletion

All data can be removed at any time by deleting prompts inside the panel or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.
