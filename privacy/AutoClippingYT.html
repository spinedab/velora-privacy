Privacy Policy - Velora Clips

Last updated: August 2026

Overview

Velora Clips is a local-only Chrome extension that provides a side panel workspace for marking moments (clips) while watching YouTube videos, organizing them into collections, and exporting them as files. It is designed with a privacy-first architecture.

Data Collection

Velora Clips does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All clips, timestamps, notes, collections, and preferences are stored exclusively in chrome.storage.local on the user's device.
  • User-controlled exports. Clip lists can be exported as files using the downloads permission, only when the user explicitly requests an export.
  • No external AI or cloud services. This extension makes no API calls to any AI or cloud service. The only remote content it touches are YouTube's own pages and public video thumbnails (img.youtube.com) for display inside the panel.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

Page Access

Velora Clips only operates on YouTube pages (*.youtube.com). It reads the current video's title, URL, and playback position when the user marks a clip. It does not read or modify any other website, does not interact with your YouTube account, and does not upload, download, or alter any video content.

Permissions Explained

  • sidePanel - renders the clip workspace in Chrome's side panel.
  • storage - saves clips and collections locally.
  • activeTab / tabs - identifies the YouTube tab and its playback position when you mark a clip.
  • downloads - exports your clip lists as files when you request it.
  • host permission for youtube.com - lets the extension read the video metadata of the page you are watching.

Data Deletion

All data can be removed at any time by deleting clips inside the panel or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.
