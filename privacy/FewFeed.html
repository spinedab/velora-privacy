Privacy Policy - FewFeed Workspace

Last updated: April 2026

Overview

FewFeed Workspace is a local-only Chrome extension that helps users plan and draft content for Facebook groups and pages. It is a manual content planner: it never publishes anything for you. It is designed with a privacy-first architecture.

Data Collection

FewFeed Workspace does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All user preferences, API keys, saved drafts, scheduled items, and activity logs are stored exclusively in chrome.storage.local on the user's device. Nothing is sent to any server operated by the extension developer.
  • No external analytics or telemetry. The extension includes a local activity log stored in chrome.storage.local for the user's own reference. This data never leaves the browser.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com when the user explicitly clicks the "Generate" button. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends the current draft goal, notes, target info, and tone/language settings to the Groq API to produce a draft suggestion.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or to any data sent to or received from api.groq.com. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Facebook Page Access

The extension includes a content script that runs on facebook.com pages. This script:

  • Reads only. It scans the visible DOM to detect group names, page names, and their URLs so the user can select a posting target from the side panel.
  • Detects the composer. It checks whether a text composer is open so the user can insert a draft manually.
  • Does not modify page content automatically. Text insertion into the composer happens only when the user explicitly clicks "Insert in composer."
  • Does not scrape private data. It reads only publicly visible navigation links (group/page names and URLs) that are already rendered on screen.
  • Does not interact with Facebook's API. No Facebook login tokens, cookies, or API endpoints are accessed.

Permissions Justification

PermissionPurpose

host_permissions: facebook.comAllows the content script to run on Facebook pages for target detection and manual draft insertion
host_permissions: web.facebook.comSame as above, for users who access Facebook via the web.facebook.com domain
host_permissions: api.groq.comSends AI draft generation requests using the user's own API key

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
