Privacy Policy - Velora Terms

Last updated: September 2026

Overview

Velora Terms is a local-first Chrome extension that reads the terms-of-service or privacy page you are on and shows what a careful reader should notice: which clause families appear, the exact sentences that triggered them, and an attention score. That analysis runs entirely on your device. An AI summary is available as a separate, optional step. It is designed with a privacy-first architecture.

Not legal advice

This extension is informational. Keyword detection misses things, language models make mistakes, and neither is a lawyer. Read the original document before you rely on anything here, and get professional advice for decisions that matter.

Data Collection

Velora Terms does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. The history of pages you analysed (title, URL, score, matched clause labels, and any summary you generated) and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • Reading is on demand. The page's visible text is read only when you click "Read this page", and only from the tab that is active at that moment. Nothing is read in the background and no other tab is accessed.
  • The page is never modified. The extension uses a shared read-only extractor; it does not click, submit, fill forms, navigate, or alter the page in any way.
  • The analysis is local. Clause detection, the attention score, the reading-time estimate and the sentence quoting all run in JavaScript on your device, with no network request and no API key required. This is the part the extension is actually built around.
  • The report export needs no permission. The Markdown report is handed to you through an anchor with a data: URL, generated in the panel — the extension does not even request the downloads permission.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

There are two optional paths, and both are triggered only by an explicit click:

  1. "Summarize with AI" sends the page's text to api.groq.com in chunks of about 6,000 characters, using your own Groq API key. It asks for clause names, verbatim quotes and one-sentence explanations, plus a plain-language summary. There are no background, scheduled or automatic API calls.
  2. "Try on-device" uses Chrome's built-in summarizer when your browser actually provides one. On that path the text does not leave the browser. If no on-device model is available, the extension says so and does nothing else — it does not silently fall back to the network.

The extension developer has no access to your API key or the pages you analyse. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Terms declares no persistent content scripts and no host permission for websites. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to read the visible text of that page at that moment.

Permissions Explained

  • sidePanel - renders the analysis in Chrome's side panel.
  • storage - saves your history and the optional API key locally.
  • activeTab - temporary access to the current page, only after you click Read this page.
  • scripting - runs the one-time read-only text extraction on the active tab.
  • host permission for api.groq.com - allows the optional, user-initiated AI summary.

Data Deletion

History entries can be deleted individually inside the panel; "Forget key" removes the API key. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
