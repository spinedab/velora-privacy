Privacy Policy - Velora Dictate

Last updated: September 2026

Overview

Velora Dictate is a local-first Chrome extension that turns speech into text in the side panel, using the speech recognition built into your browser. You dictate, edit the transcript, and copy or download it. It is designed with a privacy-first architecture, with one important disclosure about the audio, below.

Data Collection

Velora Dictate does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry, and the extension itself makes no network requests of any kind.

Important: who processes your audio

Velora Dictate uses the browser's own SpeechRecognition API. In Chrome, that API sends audio to Google's speech recognition service in order to transcribe it. This is a property of the browser, not of this extension:

  • Velora Dictate never receives your audio. The extension has no server and makes no network requests.
  • The extension cannot see, intercept or redirect what the browser sends to that service.
  • Whatever Google does with audio submitted through Chrome's speech API is governed by Google's own privacy policy, not this one.

If that is not acceptable for what you need to dictate, do not use this extension (or any browser-based dictation) for that content. We would rather say this plainly than let "local-first" imply something untrue about the audio.

The transcript, once produced, stays on your device.

How Data Is Handled

  • Local storage only. The transcript, your saved dictation history, quick phrases and preferences (language, formatting, continuous mode) are stored exclusively in chrome.storage.local on the user's device.
  • No page access whatsoever. The extension has no activeTab, no scripting, no tabs permission and no content scripts. It cannot see what you browse or read anything on any page. Recognition runs inside the extension's own side panel page, which is why there is no offscreen document either.
  • Microphone access is explicit. The first time you press Start, Chrome asks you to allow the microphone for this extension. You can revoke it at any time from chrome://extensions.
  • The microphone only runs while you dictate. It starts when you press Start and stops when you press Stop (or when you close the panel). In continuous mode the extension restarts the recogniser when the browser ends a session on its own — it does not keep listening after you stop.
  • Clipboard on demand. The clipboard is written only when you click Copy. The clipboard is never read.
  • User-controlled downloads. A .txt or .md file is saved only when you click Download.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

Permissions Explained

  • sidePanel - renders the dictation workspace in Chrome's side panel.
  • storage - saves your transcript history, quick phrases and preferences locally.
  • clipboardWrite - copies the transcript when you click Copy.
  • downloads - saves the .txt or .md file when you click Download.

There is no host permission and no page permission of any kind.

Data Deletion

The current transcript can be cleared with the Clear button; saved dictations can be deleted individually from the history. Uninstalling the extension removes all locally stored data.
