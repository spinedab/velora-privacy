Privacy Policy - Velora Seller

Last updated: September 2026

Overview

Velora Seller is a local-only Chrome extension that helps e-commerce sellers draft and organize product listings in the side panel: generate a title, bullets, description and keywords from the product facts you type, check them against per-marketplace limits, score their quality locally, and keep a catalog of saved listings. It is designed with a privacy-first architecture.

Data Collection

Velora Seller does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Product inputs, generated listings, the saved catalog, marketplace preference, and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • No page access. The extension does not read, modify, or interact with any web page. It has no content scripts, no activeTab, and no scripting permission. Everything you work on is typed or pasted into the panel.
  • Local quality checks. The listing score, per-marketplace limit validation, keyword coverage and risky-claim detection all run in JavaScript on your device, with no network request and no API key required.
  • Clipboard on demand. The clipboard is written only when you click a Copy button. The clipboard is never read.
  • User-controlled exports. The catalog is exported as a CSV file only when you click Export. Nothing is uploaded anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when you explicitly click Generate listing, Variants, or Translate listing. This request:

  • Uses your own Groq API key, which you provide and store locally.
  • Sends only the product details you entered (name, category, features, materials, dimensions, audience, price, tone) and, for Translate, the listing text being translated.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to your API key, product data, or catalog. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Permissions Explained

  • sidePanel - renders the listing workspace in Chrome's side panel.
  • storage - saves your product inputs, listings, catalog, and the optional API key locally.
  • clipboardWrite - copies a listing field or the Markdown version when you click Copy.
  • downloads - saves the catalog CSV when you click Export.
  • host permission for api.groq.com - allows the optional, user-initiated AI requests.

Data Deletion

All data can be removed at any time by deleting listings from the catalog inside the panel, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
