Privacy Policy - Velora Passphrase

Last updated: 3 September 2026

Overview

Velora Passphrase runs entirely inside your browser. It has no server, no account system and no analytics. It makes no network requests at all.

Data collection

None. The extension does not collect, transmit or sell personal data, browsing history, page content or usage statistics. There is no telemetry and no crash reporting.

What is stored, and where

It stores nothing. The extension has no storage permission.

The extension does not request the storage permission, so it has nowhere to keep anything between sessions. Closing the panel discards whatever was on screen.

Network

It makes no network requests.

The manifest declares no host permissions, so the extension cannot contact any server.

Permissions explained

  • sidePanel - The entire interface is a Chrome side panel.
  • clipboardWrite - Copies results to the clipboard when you press a Copy button.

Page access

The extension never reads or modifies the pages you visit.

Data deletion

There is nothing to delete: the extension stores no data at all.

Changes to this policy

Changes will be published with the extension and reflected in the date above.
