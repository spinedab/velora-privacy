Privacy Policy - Velora Mail

Last updated: April 2026

Overview

Velora Mail is a local-only Chrome extension that helps Gmail users draft replies and new emails with AI assistance. It is a draft-only tool: the user copies the generated draft from the side panel and pastes it into Gmail themselves. It is designed with a privacy-first architecture.

Critical Privacy Statement

This extension never sends email. It never auto-replies. It never reads your inbox, thread list, or any message you have not explicitly pasted or selected. It never submits any Gmail compose form or clicks the Send button.

The user is always the one who decides what text is written, copies the draft to the clipboard, and sends the email through Gmail as they normally would.

Data Collection

Velora Mail does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. User preferences, API keys, saved tone presets, signature templates, and draft snippets are stored exclusively in chrome.storage.local on the user's device.
  • No Gmail account access. The extension does not authenticate to Google. It does not use the Gmail API. It does not access OAuth tokens.
  • No inbox reading. The extension never scans the inbox, label list, message list, or any thread the user has not explicitly selected or pasted.
  • No sending. The extension has no code path that triggers a Gmail send action.
  • Clipboard copy is manual. The user clicks a Copy button to move a draft to their own clipboard. The extension never writes into Gmail's compose field automatically.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly asks the extension to draft, rewrite, or adjust the tone of a message. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the text the user has typed or pasted into the side panel, plus the chosen tone/length options.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or drafts. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Gmail Page Access

Host permission on mail.google.com exists so that the side panel can be associated with Gmail tabs. The extension does not parse the inbox, extract message lists, or interact with the Gmail UI beyond a read of what the user has manually selected and passed to the side panel. It never types into, submits, or sends from a Gmail compose window.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
