Privacy Policy - Velora CiteGen

Last updated: September 2026

Overview

Velora CiteGen is a local-first Chrome extension that builds academic citations from the page you are reading. It reads the citation metadata a page publishes for reference managers, lets you correct every field, and formats APA, MLA, Chicago, IEEE, Harvard and BibTeX entirely on your device. An AI fallback for missing fields is optional. It is designed with a privacy-first architecture.

Data Collection

Velora CiteGen does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Your bibliography projects (every saved reference and its fields) and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • Reading is on demand. Page metadata is read only when you click "Read this page", and only from the tab that is active at that moment. Nothing is read in the background and no other tab is accessed.
  • What is read. The metadata read is the citation information a page publishes specifically for reference managers: citation_ tags (Highwire Press), Dublin Core (DC.), Open Graph, plus the page title, language and any DOI in the text. That is the same data Zotero or Mendeley would read.
  • The page is never modified. The extension uses shared read-only extractors; it does not click, submit, fill forms, navigate, or alter the page in any way.
  • Formatting is local. All six output formats are produced by JavaScript on your device — no key, no network request, no model. This is the core of the extension.
  • Exports need no permission. .bib, .ris and .md files are handed to you through anchors with data: URLs generated in the panel; the extension does not request the downloads permission.
  • Clipboard on demand. The clipboard is written only when you click a Copy button. The clipboard is never read.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

There is one optional path: "Fill missing with AI". It is triggered only by an explicit click, and only for fields that are actually empty (authors, date, container, publisher). It sends the page's visible text to api.groq.com using your own Groq API key, asks the model to extract only what the text supports, and marks every field it filled as AI-suggested in the interface and in the saved reference. There are no background, scheduled or automatic API calls.

The extension developer has no access to your API key or your bibliography. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Accuracy

Citation styles have edge cases, page metadata is often wrong or incomplete, and a language model can be confidently mistaken. Every field stays editable for that reason, AI-filled fields are labelled, and you should check a citation against your style guide before submitting work that depends on it.

Page Access

Velora CiteGen declares no persistent content scripts and no host permission for websites. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to read that page's metadata (or, for the AI fallback, its visible text) at that moment.

Permissions Explained

  • sidePanel - renders the citation builder in Chrome's side panel.
  • storage - saves your bibliography projects and the optional API key locally.
  • activeTab - temporary access to the current page, only after you click Read this page.
  • scripting - runs the one-time read-only metadata (or text) extraction on the active tab.
  • clipboardWrite - copies a citation or an in-text citation when you click Copy.
  • host permission for api.groq.com - allows the optional, user-initiated field completion.

Data Deletion

References and whole projects can be deleted inside the panel; "Forget key" removes the API key. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
