Privacy Policy - Velora MarkUp

Last updated: September 2026

Overview

Velora MarkUp is a local-only Chrome extension that captures a screenshot of the visible tab when the user clicks a button and lets the user annotate it inside the extension's side panel. It is designed with a privacy-first architecture.

Data Collection

Velora MarkUp does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, no telemetry, and no AI processing of any kind. The extension makes no network requests.

How Data Is Handled

  • Capture on demand. A screenshot is taken only when the user clicks "Capture visible tab". The extension never captures automatically or in the background.
  • Local storage only. The last 10 captures are kept as compressed previews in chrome.storage.local on the user's device (about 4 MB total). The user can clear them at any time.
  • Clipboard on demand. The clipboard is written only when the user clicks "Copy PNG". The extension never reads the clipboard.
  • Downloads on demand. Files are saved only when the user clicks "Download".
  • No user accounts. The extension does not require or support accounts, login, or registration.

External API Usage

None. The extension does not contact any server.

Page Access

Velora MarkUp does not inject content scripts and does not read or modify the content of any web page. activeTab is used solely to capture the pixels of the visible tab at the moment the user clicks.

Permissions Explained

  • sidePanel - renders the editor in Chrome's side panel.
  • activeTab - allows capturing the visible tab when the user clicks the extension.
  • downloads - saves the annotated image as PNG or JPEG when the user clicks Download.
  • clipboardWrite - copies the annotated image when the user clicks Copy.
  • storage - keeps the recent-captures gallery locally.

Data Deletion

All data can be removed by clicking "Clear" in the panel or by uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy
