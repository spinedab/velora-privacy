Privacy Policy - Velora Tube

Last updated: September 2026

Overview

Velora Tube is a local-only Chrome extension that helps YouTube creators draft and review video metadata (titles, descriptions, and tags) using AI-assisted suggestions. It is designed with a privacy-first architecture.

Data Collection

Velora Tube does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All user preferences, API keys, generation history, and draft metadata are stored exclusively in chrome.storage.local on the user's device. Nothing is sent to any server operated by the extension developer.
  • No external analytics or telemetry. The extension includes a local activity log stored in chrome.storage.local for the user's own reference. This data never leaves the browser.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com when the user explicitly clicks the "Generate" or "Generate A/B" button. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends the current topic, detected YouTube page context, and selected generation settings to the Groq API to produce metadata suggestions.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or to any data sent to or received from api.groq.com. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

YouTube Page Access

When the user clicks "Detect Context," the extension reads publicly visible information from the active YouTube tab (video title, channel name, search query, meta keywords, and visible search result titles). This data is used locally to build the AI prompt and is never transmitted to any server other than api.groq.com at the user's explicit request.

When the user clicks "Read video" on a YouTube watch page, the extension runs a one-time read-only script in the page's main world to read the video metadata that YouTube already exposes to the page (ytInitialPlayerResponse.videoDetails: title, public tags, short description, length, view count, channel name). The result is shown in the panel and can be copied; it is not stored unless the user pastes it into a field, and it is never sent anywhere unless the user later clicks an AI action.

The local SEO score and the CTA/links block are computed entirely inside the browser and make no network requests. Saved links are stored in chrome.storage.local.

The extension never reads pages in the background, never clicks or submits anything on YouTube, and never modifies page content.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
