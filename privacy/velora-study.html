Privacy Policy - Velora Study

Last updated: September 2026

Overview

Velora Study is a local-only Chrome extension for spaced-repetition flashcard learning using the SM-2 algorithm, plus a syllabus-to-plan extractor, a pomodoro timer, a reading-time calculator and iCal export. All decks, cards, plan tasks, sessions and review data live on the user's device. AI-assisted card generation is optional and uses the user's own API key. It is designed with a privacy-first architecture.

Data Collection

Velora Study does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All decks, cards, review history, SM-2 intervals, plan tasks, pomodoro sessions, reading speed, API keys, and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Local scheduling. The SM-2 algorithm runs entirely in the browser. Review intervals, easiness factors, and due dates are computed and stored locally.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind. There is no cloud sync.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Generate with AI" (flashcards) or "Extract tasks with AI" (syllabus). This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the text visible in the panel textarea at that moment (pasted notes, a selection or a page the user chose to read) and the chosen settings.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key, decks, cards, or review data. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Study requests activeTab and scripting so that, only when the user clicks "Read active tab", "Use selected text from active tab" or "Measure active tab", it can run a read-only function in the current tab that returns the page's readable text or the current selection and a word count. The extension has no host permissions for web pages, no content scripts, and never runs in the background on pages. It never clicks, types, submits forms, or modifies any page. Text that is read appears in the panel for the user to review and is not sent anywhere unless the user then clicks an AI button.

Downloads

The downloads permission is used only when the user clicks "Export .ics", to save a calendar file generated locally from the user's own plan tasks and pomodoro sessions. A Save-as dialog is shown. No file is downloaded from the internet.

Changes to This Policy

If this policy is updated, the new version will be published alongside the extension update on the Chrome Web Store.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
