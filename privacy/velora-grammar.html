Privacy Policy - Velora Grammar

Last updated: September 2026

Overview

Velora Grammar is a local-first Chrome extension that proofreads text you paste into its side panel and explains every change it proposes. A set of checks and readability statistics run entirely on your device with no key and no network; AI proofreading is optional and uses your own API key. It is designed with a privacy-first architecture.

Data Collection

Velora Grammar does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Paste-only, no page access. The extension has no activeTab, no scripting, no tabs permission and no content scripts. It cannot read any web page. The only text it ever sees is what you paste into the panel — which is deliberate, because proofreading often involves drafts you would not want a website to touch.
  • Local storage only. Your text history (original and corrected), language and style preferences, and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • Local checks need nothing. Double spaces, repeated words, spacing before punctuation, unbalanced quotes and parentheses, overlong sentences, the English passive-voice heuristic, the Spanish commonly-confused list, and all readability statistics run in JavaScript on your device — no key, no network request, no model.
  • The diff is local. The word-level comparison between your text and the corrected version is computed on your device.
  • Clipboard on demand. The clipboard is written only when you click a Copy button. The clipboard is never read.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

There are two optional paths, and both are triggered only by an explicit click:

  1. "Proofread with AI" sends a request to api.groq.com with the text you pasted, your chosen style, and the detected or selected language. It uses your own Groq API key, which you provide and store locally. There are no background, scheduled or automatic API calls.
  2. "Try on-device" uses Chrome's built-in language model when your browser actually provides one. On that path the text does not leave the browser at all. If no on-device model is available, the extension says so and does nothing else — it does not silently fall back to the network.

The extension developer has no access to your API key or your text. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Permissions Explained

  • sidePanel - renders the proofreading workspace in Chrome's side panel.
  • storage - saves your history, preferences and the optional API key locally.
  • clipboardWrite - copies the corrected text when you click Copy.
  • host permission for api.groq.com - allows the optional, user-initiated AI proofreading request.

Data Deletion

The current text can be cleared with the Clear button; history entries can be deleted individually; "Forget key" removes the API key. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
