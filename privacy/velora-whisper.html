Privacy Policy - Velora Whisper

Last updated: September 2026

Overview

Velora Whisper is a Chrome extension that transcribes audio files from your computer using your own Groq API key, and keeps the resulting transcript on your device. It is local-first about the transcript, with one clear exception described below about the audio.

Important: your audio is uploaded

To transcribe a file, the audio is uploaded to api.groq.com using your own API key. This happens only when you press Transcribe, and only for the file you selected. There is no way to transcribe with this quality without sending the audio somewhere, so the extension says it plainly rather than implying otherwise:

  • The upload goes directly from your browser to Groq. Velora has no server and never receives your audio.
  • What Groq does with audio submitted to its API is governed by Groq's own terms and privacy policy, not this one.
  • Nothing is uploaded until you press Transcribe. Loading a file, playing it in the panel and checking its size all happen locally.

Do not use this for recordings you are not allowed to send to a third party. If a conversation is confidential, privileged, or covered by an agreement or regulation, use a transcription tool that runs entirely on your machine instead.

Also: recording other people may require their consent depending on where you live. This extension only transcribes files you already have; obtaining them lawfully is your responsibility.

Data Collection

Velora Whisper does not collect, transmit, or store any user data on servers operated by the developer. There is no analytics, no tracking, and no telemetry. The only outbound request is the one you trigger, straight to Groq.

How Data Is Handled

  • The audio file is never stored. It is held in memory while the panel is open, referenced by a temporary object URL for the player, and released when you load another file or close the panel. It is never written to chrome.storage, never cached, and never included in a history entry.
  • Local storage only. Transcripts you save to history (name, date, duration, word count, text and timestamped segments), your preferences, and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • No page access whatsoever. The extension has no activeTab, no scripting, no tabs permission and no content scripts. It cannot read any web page. Files come from your disk via drag-and-drop or the file picker.
  • Size is checked locally. The 25 MB per-request limit is enforced in the panel before any upload starts, so an oversized file never leaves your machine.
  • Clipboard on demand. The clipboard is written only when you click Copy. The clipboard is never read.
  • User-controlled downloads. .txt, .srt, .vtt and .md files are saved only when you click them.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

Two endpoints on api.groq.com, both user-initiated and both using your own key:

  1. POST /openai/v1/audio/transcriptions — sends the audio file, the chosen model, the optional language hint and responseformat=verbosejson. Triggered by Transcribe.
  2. POST /openai/v1/chat/completions — sends the transcript text to produce a summary and action items. Triggered by "Summary and action items", and only if you click it.

Permissions Explained

  • sidePanel - renders the workspace in Chrome's side panel.
  • storage - saves your transcripts, preferences and the optional API key locally.
  • downloads - saves the .txt, .srt, .vtt or .md file when you click Download.
  • clipboardWrite - copies the transcript when you click Copy.
  • host permission for api.groq.com - allows the transcription and summary requests.

Data Deletion

History entries can be deleted individually; "Forget key" removes the API key; the loaded audio is released when you close the panel. Uninstalling the extension removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
