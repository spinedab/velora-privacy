Privacy Policy - Velora Inbox

Last updated: August 2026

Overview

Velora Inbox is a local-only Chrome extension that provides a side panel copilot for Facebook Messages and Messenger: quick-reply snippets, AI-assisted drafts, and local conversation context. Every message is reviewed and sent manually by the user - the extension never sends anything on its own.

Data Collection

Velora Inbox does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Snippets, drafts, detected context, API keys, and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Human review always. The extension inserts text into the message composer only when the user clicks. It never clicks Send, never schedules messages, and never sends messages in the background.
  • Context detection on demand. Conversation context (e.g. client name, product, price mentioned) is read from the currently open conversation only when the user clicks Detect, and is processed locally.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly asks for an AI draft. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the conversation excerpt needed to draft the reply the user asked for.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key, conversations, or drafts. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Inbox operates only on facebook.com and messenger.com. Its content script reads the conversation the user currently has open (to detect context and to insert the draft the user chose) and does nothing else. It does not crawl conversation lists, does not read other tabs, and does not act without a user gesture.

Permissions Explained

  • sidePanel - renders the copilot next to your inbox.
  • storage - saves snippets, drafts, and the optional API key locally.
  • tabs - identifies the Messenger tab to connect the panel with the open conversation.
  • host permissions for facebook.com / messenger.com - allow the content script to read the open conversation and insert your chosen text into the composer.
  • host permission for api.groq.com - allows the optional, user-initiated AI draft request.

Data Deletion

All data can be removed at any time by deleting snippets and drafts inside the panel, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
