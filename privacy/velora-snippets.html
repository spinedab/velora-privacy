Privacy Policy - Velora Snippets

Last updated: August 2026

Overview

Velora Snippets is a local-only Chrome extension that provides a personal library of reusable text snippets (canned replies, templates, signatures) in the side panel, with an optional AI polish action. It is designed with a privacy-first architecture.

Data Collection

Velora Snippets does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All snippets, tags, API keys, and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Clipboard on demand. The clipboard is only written when the user clicks Copy on a specific snippet. The extension never reads the clipboard.
  • User-controlled import/export. Snippets can be exported to or imported from a JSON file only through an explicit user action. Nothing is uploaded anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Polish with AI" on a snippet draft. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the text of the snippet being polished.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or snippets. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Snippets does not inject content scripts and does not read the content of any web page. It runs entirely inside its own side panel.

Permissions Explained

  • sidePanel - renders the snippet library in Chrome's side panel.
  • storage - saves snippets, tags, and the optional API key locally.
  • clipboardWrite - copies a snippet to the clipboard when the user clicks Copy.
  • host permission for api.groq.com - allows the optional, user-initiated AI polish request.

Data Deletion

All data can be removed at any time by deleting snippets inside the panel, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
