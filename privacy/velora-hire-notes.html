Privacy Policy - Velora Hire Notes

Last updated: September 2026

Overview

Velora Hire Notes is a local-only Chrome extension that keeps private recruiting notes attached to the page you are viewing. You click Attach, and the extension stores that page's address so your notes, stage, rating, tags and next action come back the next time you open it. It is designed with a privacy-first architecture.

Data Collection

Velora Hire Notes does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • No network requests of any kind. This extension has no host permissions and makes no fetch, XHR, WebSocket or beacon calls. There is no AI, no API key and no server component.
  • Local storage only. Candidates (address, name, role, stage, rating, tags, notes, next action, stage history) and your message templates are stored exclusively in chrome.storage.local on the user's device.
  • What is read from a page, and nothing more. When you click "Attach to this page", the extension runs one read-only function on the active tab that returns exactly two values: location.href and document.title. It does not read the profile's content — no name fields, no experience, no contact details, no DOM queries at all. The name is prefilled from the page title and you edit it yourself.
  • No page interaction. The extension never clicks, submits, fills forms, navigates, connects, messages, or modifies the page in any way. It cannot act on your behalf on any site.
  • Attaching is always manual. Nothing is read in the background and no other tab is accessed. On pages where Chrome forbids injection (such as chrome:// pages), the extension falls back to the tab's own title and address.
  • Notes autosave locally. The notes field is written to local storage shortly after you stop typing, so a closed panel does not lose work.
  • Clipboard on demand. The clipboard is written only when you click a Copy button. The clipboard is never read. Messages are copied for you to paste and send yourself — the extension never sends anything.
  • User-controlled exports. A JSON backup is produced only when you click Export.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

Page Access

Velora Hire Notes declares no persistent content scripts and no host permissions at all — it does not name LinkedIn or any other site. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to read that page's address and title at that moment.

Because it never reads profile content and never automates any action, it does not scrape and it does not interact with any platform's features.

Permissions Explained

  • sidePanel - renders the notes workspace in Chrome's side panel.
  • storage - saves candidates, notes and templates locally.
  • activeTab - temporary access to the current page, only after you click Attach.
  • scripting - reads that page's address and title at that moment (nothing else).
  • clipboardWrite - copies a link or a filled message template when you click Copy.

Data Deletion

All data can be removed at any time by deleting individual candidates or templates inside the panel, using "Delete all local data" in the Data tab, or uninstalling the extension. Uninstalling removes all locally stored data.
