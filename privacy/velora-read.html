Privacy Policy - Velora Read

Last updated: September 2026

Overview

Velora Read is a local-only Chrome extension that provides a personal reading list in the side panel: save the page you are on, then read it offline, listen to it, apply Bionic Reading to the page, tag it, or summarize it on demand. It is designed with a privacy-first architecture.

Data Collection

Velora Read does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. All saved pages (title, URL, captured article text), summaries, tags, reading preferences (voice, speed), and the optional API key are stored exclusively in chrome.storage.local on the user's device.
  • Capture on demand. Page text is captured only when the user clicks "Save current page", and only from the tab that is active at that moment. Nothing is captured in the background.
  • Offline reading. The "Read offline" view displays the text that was captured at save time from local storage. It does not reload or contact the original website.
  • Summaries on demand. When the user clicks Summarize, the extension first tries Chrome's built-in on-device summarizer (if the browser provides it); in that case the text never leaves the browser and the result is labelled "on-device". Otherwise the captured text is sent to the AI provider using the user's own key.
  • Tags on demand. Semantic tags are generated only when the user clicks Tag on a specific entry, using the user's own key.
  • Read aloud. Text is spoken with the browser's speech synthesis engine. Voices flagged as "network" in the voice list are provided by the browser vendor and may be processed by that vendor; local voices keep everything on the device. The extension itself sends nothing.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks Summarize (and no on-device summarizer is available) or Tag on a saved page. This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the captured text (or summary) of the specific entry being processed.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key, saved pages, tags, or summaries. Usage of the Groq API is governed by Groq's own terms of service and privacy policy.

Page Access

Velora Read declares no persistent content scripts and has no host access to websites. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to run one of three functions on that page at that moment:

  • read the visible article text (Save);
  • apply Bionic Reading, which changes only how words are displayed by wrapping the first half of each word in a bold element inside paragraphs, lists and headings (Apply);
  • undo that change (Restore).

The Bionic transform is the only modification the extension ever makes to a page. It never clicks, submits, fills forms, navigates, or interacts with page scripts, and it cannot read any other tab or any page in the background.

Permissions Explained

  • sidePanel - renders the reading list in Chrome's side panel.
  • storage - saves entries, summaries, tags, preferences, and the optional API key locally.
  • activeTab - temporary access to the current page, only after you interact with the extension.
  • scripting - reads the article text (Save) or applies/undoes Bionic Reading on the active tab when you click.
  • host permission for api.groq.com - allows the optional, user-initiated AI requests.

Data Deletion

All data can be removed at any time by deleting entries inside the panel, clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
