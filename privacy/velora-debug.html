Privacy Policy - Velora Debug

Last updated: September 2026

Overview

Velora Debug is a local-first Chrome extension that helps developers understand errors, stack traces and code snippets they paste into the side panel, with local hints and an optional AI explanation. It is designed with a privacy-first architecture.

Data Collection

Velora Debug does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Session history, the optional API key and preferences are stored exclusively in chrome.storage.local on the user's device.
  • Local pre-processing first. Before anything can be sent, the extension detects the language, parses stack frames, replaces home directories (/Users/name, /home/name, C:\Users\name) with ~, and redacts emails, bearer tokens, JWTs, API keys, passwords, credentials embedded in URLs and public IP addresses. The panel shows the count of redactions and a preview of the exact text that would be sent.
  • History stores redacted text only. Saved sessions contain the redacted input, the detected language, matched hint titles and the AI answer, never the original unredacted text.
  • Clipboard on demand. The clipboard is only written when the user clicks Copy. The extension never reads the clipboard.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

The only external network request made by this extension is to api.groq.com, and only when the user explicitly clicks "Explain", "Suggest fix" or "Minimal repro". This request:

  • Uses the user's own Groq API key, which they provide and store locally.
  • Sends only the redacted error/code text and optional context shown in the preview.
  • Is initiated exclusively by manual user action; there are no background, scheduled, or automatic API calls.

The extension developer has no access to the user's API key or pasted content. Usage of the Groq API is governed by Groq's own terms of service and privacy policy. Local analysis and local hints work without a key and without any network access.

Page Access

Velora Debug does not inject content scripts, does not request access to any tab and does not read the content of any web page. It runs entirely inside its own side panel; all input is pasted by the user.

Permissions Explained

  • sidePanel - renders the debugging assistant in Chrome's side panel.
  • storage - saves session history and the optional API key locally.
  • clipboardWrite - copies an explanation, fix or session to the clipboard when the user clicks Copy.
  • host permission for api.groq.com - allows the optional, user-initiated AI request.

Data Deletion

All data can be removed at any time by deleting sessions inside the panel, clicking "Clear history", clicking "Forget key", or uninstalling the extension. Uninstalling removes all locally stored data.

Changes to This Policy

Any future changes to this policy will be published with an updated extension version and a new "Last updated" date.

Velora Keys

If you also use Velora Keys and have approved this extension there, this extension can ask Velora Keys for your AI API key when it has none of its own saved. The request travels over Chrome's local messaging between your own installed extensions; nothing is sent to a server. The key is used for this extension's requests to the AI provider, exactly as if you had pasted it here, and this extension does not store it. You can revoke the approval in Velora Keys at any time.
