Privacy Policy - Velora MarkdownWeb

Last updated: September 2026

Overview

Velora MarkdownWeb is a local-only Chrome extension that converts the article you are reading into clean Markdown, in the side panel. It extracts the main content of the page you explicitly ask it to convert, turns it into Markdown on your device, and lets you preview, copy or download the result. It is designed with a privacy-first architecture.

Data Collection

Velora MarkdownWeb does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • No network requests of any kind. This extension has no host permissions and makes no fetch, XHR, WebSocket or beacon calls. There is no AI, no API key and no server component. Conversion is pure local JavaScript.
  • Local storage only. Conversion options (images, links, front matter, heading offset) and the history of your last conversions (title, URL and the Markdown text) are stored exclusively in chrome.storage.local on the user's device.
  • Capture on demand. The page is read only when you click "Convert this page" or "Selection only", and only from the tab that is active at that moment. Nothing is read in the background and no other tab is accessed.
  • The page is never modified. The injected function is read-only: it returns the markup of the main content node and the page's title, URL, byline and date. It does not click, submit, fill forms, navigate, or alter the page in any way.
  • Parsing happens in the panel. The captured markup is parsed with DOMParser inside the extension's own panel, not on the live page, so page scripts never interact with the conversion.
  • Clipboard on demand. The clipboard is written only when you click Copy. The clipboard is never read.
  • User-controlled downloads. A .md file is saved only when you click Download.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

Page Access

Velora MarkdownWeb declares no persistent content scripts and no host permissions. It uses the activeTab permission, which grants temporary access to the current tab only after an explicit user gesture, together with scripting to run one read-only function on that page at that moment.

Permissions Explained

  • sidePanel - renders the converter in Chrome's side panel.
  • storage - saves your conversion options and local history.
  • activeTab - temporary access to the current page, only after you click Convert.
  • scripting - runs the one-time read-only extraction on the active tab.
  • downloads - saves the .md file when you click Download.
  • clipboardWrite - copies the Markdown when you click Copy.

Data Deletion

All data can be removed at any time by clearing the history inside the panel or uninstalling the extension. Uninstalling removes all locally stored data.
