Privacy Policy - Velora Access

Last updated: September 2026

Overview

Velora Access is a local-only Chrome extension that applies readability and accessibility adjustments (typography, contrast, color inversion, cursor size, text scale, a reading ruler, read-aloud) to the page you are viewing, only when you click, and removes them on request. It makes no network requests of any kind.

Data Collection

Velora Access does not collect, transmit, or store any user data on external servers. There is no analytics, no tracking, and no telemetry transmitted outside of the browser.

How Data Is Handled

  • Local storage only. Your last-used settings and the settings you choose to save per website (keyed by hostname) are stored exclusively in chrome.storage.local on the user's device. The stylesheet currently applied to a tab is remembered in chrome.storage.session (cleared when the browser closes) so it can be removed again.
  • Page changes on demand. The extension changes a page only when you click "Apply to page": it inserts a stylesheet and, if enabled, one overlay element for the reading ruler. "Reset page" removes both. Reloading the tab also removes them.
  • Read aloud. When you click "Read selected text", the text you selected on the page is read by the browser's built-in speech synthesis inside the extension. It is not stored and not sent anywhere.
  • No user accounts. The extension does not require or support user accounts, login, or registration of any kind.

External API Usage

Velora Access makes no network requests of any kind. It does not call any AI provider or any other service.

Page Access

Velora Access does not declare content scripts and has no host permissions. Access to a page is granted per click through activeTab. The only code executed on the page inserts or removes a stylesheet, adds or removes the reading-ruler overlay, or reads the current text selection. It never clicks, types, submits forms or reads anything other than the selection.

Permissions Explained

  • sidePanel - renders the controls in Chrome's side panel.
  • storage - saves your last-used and per-site settings locally.
  • activeTab - grants temporary access to the current tab only after you click, so the adjustments can be applied to it.
  • scripting - inserts and removes the stylesheet, toggles the reading ruler and reads the selected text in the active tab, on click.

Data Deletion

Per-site settings can be removed with "Forget site" inside the panel. Uninstalling the extension removes all locally stored data.
